# 在线全市场流程

入口：`bash run.sh [--target-code CODE] [--output-dir PATH] [--workers 1..8] [--top-lists] [--force-refresh] [--calendar-file PATH]`。Windows入口为 `run.ps1`；安装系统依赖由使用者完成，脚本仅创建自己的Python虚拟环境。

1. 实时下载全市场目录，选债券型及债券QDII；交易日实时读取批量排名，休市日目标轻量探测未变时复用24小时内境内排名，QDII排名独立刷新。排名按分页总数严格去重校验。目录遗漏、重复或总数变动属于关键失败，不以排名前几名替代目录。
2. 目标最新公开净值确定共同截止日，校验不晚于今天、不落后市场最新日期、不跨年、不超过14天。真实净值日与上海执行日分开展示。最新并不意味着当天一定已有公开净值。
3. 按逐份额净值日与版本处理差集；日期已对齐且完整的详情可复用，旧日／缺失／失败继续补拉。全目录查身份/币种/成立时间，目录身份不变且7天内可复用。缺失当前数据留空；不混用旧日收益。
4. 先按必然触发R3的整个份额组预筛，其余组查完整年度，保留组内所有份额用于历史核查。年度数据按身份、截止年、解析版本及完整性复用7天，失败／缺年／收益冲突重试。基本资料的同全称、管理人、币种只作为**临时身份检索组**，不能直接作为正式补全证明。
5. 利用数值条件确定完整报告核查范围。最终计算前，份额关系必须由管理人最新完整定期报告中的身份和代码交叉核对；未核实关系不能补全。补全只借原始份额数据，不能链式转借。
6. 实时获取从2020年起的公告目录，按已披露报告期和发布日期选择最新完整报告、最新招募说明书及各全年报告。公告编号未变且下载7天内、哈希一致的PDF可复用；全文按文件及解析器哈希复用，解析冲突重取。每轮核对身份、资产组合、债券品种、全份额净资产、年度收益和已确认异常事件。实际持仓例外额外核查交易报告及其他资产明细。疑点不能改标为clear。
7. 当前天天基金交易状态在正式计算前重新查，开放/正额度限购可参加；零额度、停购剔除；无法确认观察。执行跨过上海日期时停止以免旧核查日冒充当前状态。
8. 复用原有精确Decimal筛选引擎，按三类与原始今年收益降序导出 Markdown、CSV、JSON、覆盖、补全和证据。保存新时间戳目录，关键失败不更新latest指针，不自动加载旧报告兜底。

全市场数值预筛只是避免下载已必然失败基金的全部PDF，不改变检索起点，也不声称所有目录基金已完成逐只持仓研究。`market_audit.json`保留阶段剔除和未完成记录；任何源数据/解析失败均披露，未完成项不正式入选。合同许可的非股票风险资产也需要本报告期未投资的明确依据，不能仅凭期末仓位为零证明全年从未投资。规模须确认人民币单位及全份额金额，不能把外币或单份额金额直接当作总规模。

年度净值增幅低于15点异常阈值并不自动可信。报告中的明确非经常性净值事件剔除，怀疑事件或年度收益与管理人报告不一致则待核实。文本解析能力有限，不能保证识别所有隐含事件；复杂基金仍需要研究者复核。

报告解析兼容带空格／换行的份额标题及相同重复收益表，财务指标备选仅在年度和份额列可确认时使用。风险提示不当作已发生事件，其他资产只核对本表合计。某份年报下载或解析失败时保留该年具体诊断并继续核查其他年度，不把失败当作没有历史或默认无异常。报告与CSV的正式入选门槛不变；待核实详情另存`pending_funds.json`，核验环节另存`verification_issues.json`。两者与HTTP失败分别统计，任何缺口仍以退出码3结束。

历史固定R1/R2集合2020—2025不随程序自动变化，三五年年化与所有完整年度严格正收益检查按最新日历年推进；完整年度0%、-0%和负收益均剔除。默认目标400030保存在defaults；CLI覆盖仅本次生效。

详细周一分批更新、周末／休市日、缓存期限、QDII独立探测和静默修订边界见[缓存与更新策略](cache-policy.md)。缓存只保存源数据；每轮重新计算资格，`cache_audit.json`保存逐份额真实净值日及重试标签，不以执行日期冒充净值日。

国债期货使用独立的用途、合同许可和品种／多空持仓核查；不能把所有期货或“金融衍生品投资”总类一概当成权益。股票、普通可转债、可交换债等实际敞口及明确期内交易仍剔除；核心披露缺失仍观察，仅缺全期否定声明按备注保留规则处理。

输入份额和正式份额组按代码规范化，避免并发返回顺序干扰审计。导出`decision_audit.json`，记录规则／代码、完整输入、结果哈希及相邻已发布轮次的可比较性。相同规则／代码与输入的不同结果阻止发布；历史文件仅用于比较，不提供候选。模型只能解释结构化状态，不能口头追加规则、把待核实说成硬剔除或在原报告上手改名单。

股票交易总额“注：无”、国债期货空模板、基金份额持有人赎回款与真实基金投资分别解析。历史名称核对采用最新官方说明书原合同生效名称及代码交叉验证，结果留存原件来源；不读人工补核结论来给基金放行。审计逐基金收益指纹与核验问题，解释名单变化时明确是收益、规则还是核验状态改变，无法比较如实标明。

报告后相关公告自动取得原件并保存`later_announcement_reviews`，不是看到标题就永久待核实。业绩比较基准调整公告明确修订合同的未来生效日、基金身份一致、现有合同及同日更新合同均确认纯债时，可在生效日前继续按现行合同核查；不提前将未来合同当作已经生效。到生效日、身份／范围不明或涉及转型、清算、收益更正等情况仍待核实，不能仅凭标题或旧人工补核记录放行。

同一份额的年度平台值／官方值差异分别保存，超差或正／零／负收益边界不同不改`matched`也不直接当异常。资格计算前按来源上下界和年度异常最不利组合检查，并覆盖同基金其他份额与补全来源；资格稳定时备注保留，影响门槛时待核实。输出`disclosure_notes.json`及CSV备注，表内※仍属于原三类且按今年收益排序。缺失、解析失败、零收益、负收益或实际非纯债交易不能靠备注放行。
