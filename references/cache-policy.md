# 缓存与更新策略

缓存只加速原始数据取数和全文提取，不放宽资格、冻结入选名单或替代全市场目录。

## 日期与分批更新

- 执行时间使用上海时区；数据标签使用来源真实净值日，不等于执行日或推测的交易日。
- 每轮实时获取完整债基目录并核对分页；新增份额和目录变化使对应缓存失效。历史名单从不作为候选库。
- 境内交易工作日每次读取批量排名，检测新日期和同日收益修订。逐基金保存实际净值日、内容哈希、抓取时间、完整／待补状态。
- 对齐目标同一截止日；排名缺失、收益字段缺失或旧日份额逐只补查。恰好到共同截止日且完整的详情可复用，历史字段无需因净值日期前进全部重下载。
- 周一第一次只有部分基金更新：更新的保留各自周一标签，未更新的保留真实旧日标签；下次批量探测并补查旧日／失败项。目标落后于市场新日期时停止正式比较，但保存已取得的新数据，不能降级冒充完整。
- 每次都重新计算数值门槛、官方报告核验和分类。更换目标时从完整目录重新计算；原始身份和年度历史可复用，不只检索上轮合格基金。

## 周末与休市

- 周六、周日均为境内非交易日，包括政府调休工作日。内置`trading-calendar.json`来自文件注明的交易所休市公告，目前覆盖2026年。
- 可用`--calendar-file PATH`覆盖日历，JSON须有非空`source`与ISO日期字符串数组`holidays`。须依据交易所休市安排，不用政府调休日推断开市；未覆盖年份的工作日保守重新探测批量排名。
- 休市日实时读取目标阶段收益作轻量探测，目标日期和收益未变、目录指纹匹配且排名快照不超过24小时才复用境内批量排名。没有快照、探测失败或目标内容变化则重新取排名。
- 周日使用周五最新净值，不会仅因不是周日日期而重新下载全部历史；第一轮或快照超过24小时会重取一次排名，后续同日调用可复用。未达共同截止日或请求失败的详情仍补拉。
- QDII批量排名每次刷新，避免境内休市、海外交易或披露时间不同导致误判；不让境内休市标签冻结海外数据。

## 分层保存与重试

|层级|复用条件|失效与更新|
|---|---|---|
|全市场目录|不缓存供筛选使用|每轮实时请求并核对|
|境内批量排名|休市日、目标轻探测一致、目录指纹一致、24小时内|交易日每轮请求；新目标数据／目录变化／超时重取|
|逐份额阶段收益|共同净值日一致、字段完整、来源解析版本一致|新日期／同日修订更新，旧日／缺失／失败补拉|
|基本身份|目录条目与解析版本一致、7天内|新增／名称变化／过期重取；官方份额关系每轮核对|
|完整年度收益|身份、截止年度、解析版本一致、7天内、自身完整年度齐全|缺年／失败／平台与官方冲突重试；真实0和负数不覆盖|
|报告PDF|当轮公告目录确认编号，来源、文件哈希一致、下载不超过7天|新公告／损坏／过期／明确解析或身份冲突重取|
|PDF提取全文|PDF哈希、文本哈希、解析器代码与pypdf版本一致|文本损坏或解析器升级重新提取|
|公告目录、当前申购|不复用上轮状态|本轮实时查；无法确认不入选|
|资格、排序与入选结论|不缓存供筛选使用|每轮重新核查和计算|

缺少完整年度不等于成立晚，失败不缓存为成功。新份额没有自身完整年度时可保留真实空历史，之后仍须通过官方同基金份额补全才能满足筛选历史要求。过期请求失败不回退旧值冒充新值；缓存异常不得解除待核实或篡改数据。明确收益解析冲突使相关年度与报告重新获取；核心持仓证据不足每轮重新核查，不能默认纯债。

已记录双方数值且通过资格敏感性检查的备注保留差异，不是解析失败，不要求每轮重复下载同一原件；按原7天有效期、公告编号及内容／解析版本哈希复核。仅缺全期否定声明的持仓备注亦不伪造补齐状态。影响资格、来源无法识别、新公告、内容改变或缓存过期时仍重取；备注结论每轮重算，不缓存旧入选名单。

## 审计与强制刷新

数据库为输出根目录下`.cache/market.sqlite3`，报告缓存位于`.cache/documents/`。版本指纹及哈希控制复用；成功数据原子写入SQLite，失败标记待补。并行任务共享锁；更早净值日不能覆盖已取得的较新日期。

每次输出`cache_audit.json`，包含执行时间、目标共同截止日、各层命中／更新／未变／失败次数、当前目录逐份额实际数据日期及待补标签、原始抓取时间和内容哈希。复用时间不冒充原始下载时间。`coverage.json`区分年度新请求与缓存复用；正式结果与缺口退出码沿用原规则。

```bash
bash run.sh --force-refresh
bash run.sh --target-code 015736 --force-refresh --output-dir ./results
```

强制刷新绕过全部可复用源数据和PDF，但仍实时获取目录与公告、校验日期、遵守限流和原筛选规则。更换输出根目录相当于新建缓存；第一次需要完整取数。

轻量目标探测不能保证立即发现所有其他基金的同日静默修订；休市排名最多24小时，身份／历史／同编号PDF最多7天后重取。公告变更和官方收益交叉核对可提前触发重取；怀疑修订可强制刷新，不宣称零延迟或保证源站可用。缓存不会让未核验数据自动变合格。
